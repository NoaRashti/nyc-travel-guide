# Manhattan Explorer

Manhattan Explorer הוא אתר שמציג אטרקציות במנהטן עם מידע מ-Wikipedia.

אפשר לחפש אטרקציה לפי שם, לפתוח עמוד עם מידע נוסף, לשמור מקומות במועדפים ולקבל הצעה אקראית בעמוד Discover.

המועדפים נשמרים ב-`localStorage`, ולכן הם נשארים גם אחרי רענון של הדף או כניסה מחדש לאתר.

הפרויקט נבנה עם React, Vite, TypeScript, React Router ו-Vitest.

## עמודים

- **Explore** (`/`)  
  מציג רשימה של אטרקציות במנהטן עם אפשרות חיפוש לפי שם.

- **Attraction Details** (`/items/:id`)  
  מציג מידע נוסף על האטרקציה, תמונה וקישור לערך המקורי ב-Wikipedia.

- **Favorites** (`/favorites`)  
  מציג את האטרקציות שנשמרו במועדפים. המועדפים נשמרים ב-`localStorage`, כך שהם לא נמחקים אחרי רענון של הדף.

- **Discover** (`/discover`)  
  מציג אטרקציה אקראית עם מידע נוסף ואפשרות לבחור מקום אחר.

- **404 - Page Not Found**  
  אם נכנסים לכתובת שלא קיימת באתר, מוצגת הודעת `Page not found` וקישור חזרה ל-Explore.

## הרצת הפרויקט

מתקינים את החבילות:

```bash
npm install
```

מריצים את האתר:

```bash
npm run dev
```

אחרי ההרצה פותחים בדפדפן את הכתובת שמופיעה בטרמינל.

## בדיקות

להרצת הבדיקות:

```bash
npm test
```

הבדיקות נכתבו עם Vitest ובודקות את הלוגיקה של הפרויקט, כמו עיבוד המידע מ-Wikipedia, חיפוש, מועדפים, שמירה ב-`localStorage` ובחירת אטרקציה אקראית.

כדי לפתוח את Vitest UI:

```bash
npm run test:ui
```

## Build

כדי לבדוק שהפרויקט נבנה בלי שגיאות:

```bash
npm run build
```

## Wikipedia API

המידע באתר מגיע מ-Wikipedia דרך MediaWiki Action API:

https://en.wikipedia.org/w/api.php

ה-API הוא ציבורי ולא דורש מפתח.

האתר משתמש בו כדי:
- לקבל רשימה של אטרקציות במנהטן.
- לקבל מידע נוסף על אטרקציה לפי ה-`pageid` שלה.

## Favorites

המועדפים נשמרים ב-`localStorage` של הדפדפן.

בכל פעם שמוסיפים או מסירים אטרקציה מהמועדפים, הרשימה המעודכנת נשמרת. כשמרעננים את הדף או נכנסים שוב לאתר, המועדפים נטענים מחדש מה-`localStorage`.

ככה ה־`localStorage` כבר לא נראה כמו הערה קטנה בסוף, אלא חלק ברור מהפיצ'ר של Favorites וגם מהבדיקות.
